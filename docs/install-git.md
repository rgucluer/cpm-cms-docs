## Ubuntu 24.04, Debian 13, Pop OS

On Developer PC

```bash
sudo apt install git-all -y
```

## Set options for git:
```bash
git config --global user.name "< github-name-surname >"
git config --global user.email < github-user-email >
git config --global core.editor nano
git config --list
```
